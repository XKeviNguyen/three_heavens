## P2 FLOW-IMPORT-001 — older import overwrites a newer source edit

Affected code: `app/javascript/controllers/workspace_upload_controller.js:35-47`, particularly assignment at line 47 and autosave notification at line 58.

Reproducer:

1. Sign in, open New translation, and enter `Initial source before import`.
2. Choose Upload file and upload a synthetic TXT containing `Imported source from older action`.
3. Hold the successful `/source_imports.json` response after server processing, before the upload controller receives it.
4. While the import appears pending, switch to Paste text and enter `Newer typed source wins`. The textarea is editable and displays the new value.
5. Release the older upload response.
6. The textarea becomes `Imported source from older action`. Wait for autosave, then refresh: that older value remains.

**Violated invariant:** newest authoritative user action wins; older async completion must not replace later edits or make their loss durable.

**Root cause:** the completion guard checks only whether `requestKey` still belongs to the upload. Editing source or switching to paste does not change that key. The controller unconditionally replaces source text, installs import provenance and emits the input event that autosaves the overwritten value.

**Impact:** ordinary user behavior during slow extraction/network response silently loses newer pasted/typed text. Refresh cannot recover it. This requires no AI/provider call.

Evidence under the audit root:

- `flow/adversarial_flow_test.rb`: deterministic real-browser held-response probe.
- `flow/adversarial-confirmed.log`, seed 40167: expected newer source, observed older imported source; 1 run / 4 assertions / 1 intentional regression assertion failure / 0 errors.
- `flow/adversarial-durable-confirmed.log`, seed 51205: older imported source observed in the textarea, encrypted server draft and refreshed page; 1 run / 5 assertions / 1 intentional regression assertion failure / 0 errors.
- `flow/FLOW-IMPORT-001.png`: screenshot after refresh.

Executable confirmation in this isolated audit environment (start the preserved audit PostgreSQL container first if it is stopped):

Minimal correction: include source-edit ownership in upload completion. Capture the source-edit generation at upload start, invalidate ownership on later source edits, and suppress both old source replacement and old provenance installation when superseded.
