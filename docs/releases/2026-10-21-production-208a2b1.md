## Review findings fixed before deploy

Codex reviewed #108 and #109. `main` was merged before the findings were fixed, so #110 fixed them before anything was deployed:

| Severity | Finding | Fix |
| --- | --- | --- |
| P1 | A retried cut-off answer's billed cost disappeared from history and pipeline totals | Totals add billed provider attempts that their run no longer shows (`Pipelines::EarlierAttemptCosts`); each request is counted once |
| P1 | A stale Admin → AI key page could replace a newer platform key | The form posts the key it showed; replace and remove are refused under the row lock if it changed |
| P2 | During a catalog outage the reviewer, judge and refiner pickers were empty | They offer saved models that have already finished that kind of step |
| P2 | A billed cut-off answer's known cost was marked incomplete | Cost and token completeness follow the reported usage |

Codex could not review #110 (usage limit reached). An independent read-only review found no blockers, and its three minor findings were fixed in the same PR.

## Rollback

`e4099f6` is the code rollback target and runs on the new schema. The new table is unused by it, the new columns are nullable, and the trigger only relaxes a check for replaced runs. Never run `db:rollback`; the second migration refuses to roll back once a run has been replaced. Do not roll back to a release before bring-your-own-key billing (`20261010090100`).
